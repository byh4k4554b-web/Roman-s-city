# Security Policy

Roman's City is a static web page (a single `index.html`) served by GitHub Pages. It has no server, no user accounts, no payments and no secrets in the code. Purchases happen on Depop or eBay, never on this site.

## Reporting a vulnerability

Please **do not open a public issue** for security problems.

Report it privately instead: go to the **Security** tab of this repository and click **Report a vulnerability**. Include what you found, the steps to reproduce it and the browser/device you used.

We will review every report and fix confirmed issues as soon as we can. Please give us a reasonable time to fix a problem before sharing it publicly.

## Scope

In scope: the code in this repository and the site at https://byh4k4554b-web.github.io/Roman-s-city/ (for example, ways to run code in another player's browser, or to send players to a non-Depop/eBay link from a Buy button).

Out of scope: Depop, eBay and GitHub themselves (report those to each company), and denial-of-service or spam testing.
